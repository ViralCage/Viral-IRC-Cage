# Viral Cage — Unity 3D Bike Racer

This is a separate Unity project. It does not modify the existing `test/index.html` game or any other website game.

## Engine
- Unity 6.3 LTS (6000.3)
- Target: Unity Web platform (WebGL/WebAssembly)
- Input: keyboard plus on-screen mobile controls
- Vehicle: Rigidbody + WheelCollider-based motorcycle prototype
- Race: closed circuit, checkpoints, lap counter, basic AI traffic

## Open the project
1. Install Unity Hub and Unity Editor 6.3 LTS.
2. Add **Web Build Support** in Unity Hub > Installs > Editor > Add modules.
3. Open this folder (`unity-bike-racer`) as a Unity project.
4. In Unity, run **Viral Cage > Build Prototype Scene** from the menu.
5. Open `Assets/Scenes/BikeRacer.unity` and press Play.

The scene is generated by the editor utility so the project stays text-based in Git until opened in Unity.

## Web publishing
Use File > Build Profiles > Web, switch platform, then build. Upload the generated build output to a dedicated route such as `/test-unity/`. Do not replace `/test/` until the Unity build has been tested on desktop and mobile.

## Current scope
This is the first engine foundation, not a finished production game. It establishes the Unity project, vehicle physics, follow camera, procedural test circuit, checkpoints, and basic traffic. Proper licensed bike/rider art, tuned motorcycle suspension, polished UI/audio, and online multiplayer remain separate production tasks.
